# Vertrag Backend ↔ Frontend (Ordo)

Hier beschreibt das Backend die Store-API, die das Frontend (Storefront) nutzt: Routen, Anfragen und Antworten
als JSON-Schema (`schema/`) und Beispielfälle (`fixtures/`). Vertragsänderungen zuerst auf einem Branch
`contract/<thema>` nach `main`, dann umsetzen. Nur erweitern, nie brechen. Noch leer – entsteht mit dem ersten
Frontend-Schritt.
